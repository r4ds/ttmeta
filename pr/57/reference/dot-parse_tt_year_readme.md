# Extract the weekly summary table from a TidyTuesday readme

Extract the weekly summary table from a TidyTuesday readme

## Usage

``` r
.parse_tt_year_readme(year, token = gh::gh_token())
```

## Arguments

- year:

  The year to extract.

- token:

  GitHub token.

## Value

A table of information about TidyTuesday weeks for that year.
